# 🛒 E-commerce Website

A simple and user-friendly e-commerce website that allows users to browse products, view prices, add products to a shopping cart, and navigate through dedicated Home, About, Contact, and Login pages.

The project is developed using frontend web technologies and demonstrates the basic functionality and structure of an online shopping platform.

## ✨ Features

* 🏠 **Home Page** – Displays available products with images and prices.
* 🛍️ **Product Listing** – Browse different products available in the store.
* ➕ **Add to Cart** – Add products to the shopping cart.
* 🛒 **Shopping Cart** – View and manage selected products.
* 💰 **Product Pricing** – Displays the price of each product.
* 🔐 **Login Page** – Provides a dedicated login interface.
* ℹ️ **About Page** – Provides information about the store.
* 📞 **Contact Page** – Provides a contact interface for users.
* 🖼️ **Product Images** – Includes images for the listed products.
* 📱 **Responsive Interface** – Designed for a simple and user-friendly shopping experience.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Sangeetha-ms5/E-commerce-website.git
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd E-commerce-website
```

### 3. Run the Website

Open `index.html` in a web browser.

For development, you can also use **Visual Studio Code with the Live Server extension**.
